# CONTRIBUTING.md

## CSC2105 Group 6 GitHub Contribution Guide

This repository uses GitHub collaboration to develop one final submission file: `Group6_System.py`.

## Workflow

1. Clone the repository.
2. Create a feature branch.
3. Make your changes.
4. Commit using a meaningful message.
5. Push your branch.
6. Open a Pull Request.
7. Team Lead reviews and merges into `main`.
