# Project Report

## CSC2105 Topic 5 – HR / Payroll System

## 1. Introduction

A small organisation requires software to calculate weekly salaries for employees.

## 2. Objectives

- Apply Object-Oriented Programming.
- Calculate gross pay.
- Calculate overtime.
- Calculate tax.
- Generate payslips.

## 3. System Design

### Employee Class

Stores employee information and performs payroll calculations.

### PayrollSystem Class

Stores multiple Employee objects and manages payroll operations.

## 4. Payroll Algorithm

1. Calculate regular pay.
2. Calculate overtime pay.
3. Compute gross pay.
4. Apply tax.
5. Compute net pay.

## 5. Exception Handling

Invalid inputs are rejected using ValueError.

## 6. Testing

The system demonstrates valid and invalid employee records.

## 7. Future Improvements

- Database persistence.
- GUI interface.
- Employee inheritance hierarchy.
