# Weekly Salary Payroll System

**CSC2105 – Object-Oriented Programming Using Python**

Group 6 project for Uganda Christian University.

## Project Overview

This project models a payroll management system using Object-Oriented Programming principles in Python. It calculates weekly salaries, overtime pay, tax deductions, and net pay while refusing invalid operations through exception handling.

## Assignment Requirements Covered

- Employee class with attributes and methods.
- PayrollSystem class managing multiple employees.
- Weekly salary calculation.
- Overtime calculation (1.5× after 40 hours).
- Tax deduction.
- Payslip generation.
- Invalid actions rejected using exceptions.

## OOP Concepts Used

| Concept | Implementation |
|---------|----------------|
| Class | Employee, PayrollSystem |
| Object | Employee instances |
| Constructor | __init__ |
| Encapsulation | Salary calculations inside Employee |
| Methods | calculate_tax(), generate_payslip(), etc. |
| Exception Handling | ValueError and try/except |
